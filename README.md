# Description
This repository contains a Multi-Client Server Chat Application built using Java Sockets. The application allows multiple clients to connect to a server and communicate with each other in real-time.
Creating a  Java server-client chat application involves using sockets for communication. 
Below is a basic implementation of a chat application, where the server can handle multiple clients using threads.
it is multi client chatting applications after connecting with servers then the clients can talk to each other 
# Features
- Supports multiple clients
- Real-time messaging
- Server handles client connections
- Simple command-line interface
- Thread-based client handling

# Prerequisites
- Java Development Kit (JDK) installed
- IDE or text editor of your choice
